# Sample data (~1MB)

Tiny patches for smoke-testing the pipeline. Not the full training/eval set.

- `clean_patch.npy`: shape (256, 256), dtype float32
- `noisy_patch.npy`: shape (256, 256), dtype float32 (sigma≈0.05 synthetic)

Full datasets: see `seismic_denoising/WHAT_TO_DOWNLOAD.md` and `DATA_MANIFEST.md`.
